# East County Family Dental Center — Landing Page Prototype

A responsive, single-page website concept for East County Family Dental Center in El Cajon, California.

## Preview locally

Open `index.html` in a browser. The page is plain HTML, CSS, and JavaScript; no build step is needed. The design uses Google Fonts when online, with system-font fallbacks.

## Included
- Responsive navigation and mobile menu
- Appointment and click-to-call calls to action
- Practice approach, care categories, patient testimonial, contact details, and hours
- A local office photo from the practice's denTEL location listing
- Typographic wordmark rather than a recreated official logo

## Before launch
This is a design prototype, not a production deployment. Confirm current hours, treatment details, testimonial permissions, branding/image usage rights, accessibility, privacy/cookie requirements, analytics, and appointment form behavior with the practice. Appointment requests link to the existing practice site; no new booking backend is included.
